rclone-123

A personal Google Drive connection for one person

rclone-123 is a private app with exactly one user: its owner. It lets rclone, the open-source file-sync program, running on the owner's own computer, copy files to and from the owner's own Google Drive.

It is not a service, it is not offered to anyone else, and it has no server of its own. Everything happens between one computer and one Drive account, both belonging to the same person.

How it handles data is set out in the privacy policy.
